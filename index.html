Questions

Is it really free?

Yes. Qyra is open source under GPL-3.0. There is no trial, no paid tier and no subscription.

Does it upload my PDFs?

No. Every tool runs on your computer. There is no account and no telemetry. The only network request Qyra makes is a check on GitHub for a newer version.

Can it replace Acrobat?

For everyday PDF work, yes: reading, highlighting, comments, signatures, forms, redaction, merging, splitting, compressing, OCR and converting. It does not rewrite the text of a PDF like a word processor, and it has no AI assistant.

Is there a Mac version?

No. Qyra is built and tested on Linux and Windows only.

Does it work without internet?

Yes, completely, OCR included.

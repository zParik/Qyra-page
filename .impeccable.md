## Design Context

### Users
People actively searching for PDF tools — "PDF viewer", "PDF editor", "split PDF", "compress PDF", etc. They've likely already been burned by Adobe's subscription wall, iLovePDF's cloud uploads, or Foxit's bloat. They arrive skeptical and task-oriented. The site needs to convert them fast: answer "what is it, why should I trust it, how do I get it" within the first scroll. Privacy-conscious users and open-source advocates are a core secondary audience who will read the GitHub link as a trust signal.

### Brand Personality
Sharp, dependable, anti-bloat. Confident without being loud.
- **Anti-Adobe**: The brand earns credibility through restraint — no pricing tables, no "Start Free Trial", no modal popups. The absence of that noise *is* the message.
- **Open-source utility with taste**: Feels made by someone who uses tools seriously. Not a startup, not a SaaS — a well-crafted piece of software.
- **Precise but human**: Strong typographic hierarchy, intentional asymmetry, purposeful color.

### Aesthetic Direction — "Terminal Precision"
Editorial brutalism meets precision engineering. A PDF tool built by engineers who have taste.

- **Theme**: Dark-first. Deep near-black warm base (`oklch(9% 0.008 30)`). Not "dark mode" — a deliberate material choice.
- **Typography**:
  - `Syne` (variable) — oversized editorial display. Geometric, tense, unforgettable.
  - `JetBrains Mono` — labels, section markers, metadata. Reinforces precision/engineering.
  - `DM Sans` — body text. Warm, readable, human.
  - NO Geist (too generic/Vercel-associated), NO Inter, NO Roboto.
- **Color System**:
  - Base: `oklch(9% 0.008 30)`
  - Surface: `oklch(13% 0.009 30)`
  - Elevated: `oklch(18% 0.010 30)`
  - Border: `oklch(26% 0.010 30)`
  - Brand Red: `oklch(62% 0.24 18)` — hot, saturated, Qyra's identity color
  - Text Primary: `oklch(96% 0.004 80)` — warm off-white
  - Action Blue: `oklch(58% 0.20 250)`
- **Layout**: Asymmetric. Break the grid intentionally. Oversized type that partially overflows. Left-aligned default. Centering is a deliberate choice, never the default.
- **Motion**: Staggered character reveals on hero. Scroll-triggered translate + opacity. Expo easing. No bounce.
- **References**: Stripe engineering blog, Railway.app, tRPC.io
- **Anti-references**: iLovePDF, Smallpdf, gradient-text SaaS, cyan/purple glow dark mode

### Platform
Windows and Linux only. No macOS. Explicit and unapologetic.

### Page Structure
1. **Hero** — Massive asymmetric headline, value prop, CTAs, platform badges
2. **Trust bar** — 4 pillars displayed as a manifesto
3. **Features** — Editorial layout, not a card grid. Primary features get full treatment; secondary features are a dense list.
4. **Download** — Explicit platform breakdown
5. **Footer** — Minimal. GitHub + license only.

### Design Principles
1. **Convert through credibility** — No hype, no "free for 30 days". Concrete facts earn the download.
2. **Type does the heavy lifting** — The headline IS the design.
3. **No AI fingerprints** — No identical card grids, no glassmorphism, no gradient text.
4. **Platforms are first-class** — Windows and Linux named everywhere.
